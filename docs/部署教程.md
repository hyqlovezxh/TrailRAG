# 部署教程（Deployment Guide）

本教程说明如何在本机部署并启动 **语溯开源版（TrailRAG / YUSU）** 知识库系统：一个 Python 后端（FastAPI + Uvicorn，端口 8920）加一个 React 前端 WebUI（`yusu_webui`）。

快速上手请直接使用 [一键部署脚本](../scripts/start.ps1)（Windows，见 §四）。

---

## 一、环境要求

| 组件 | 版本要求 | 说明 |
|---|---|---|
| Python | ≥ 3.11 | 后端运行时 |
| uv（推荐） | 最新 | Python 依赖管理；或用 `py -m pip` 代替 |
| Bun | ≥ 1.1 | 前端依赖管理与构建 |
| 网络 | — | 首次安装需联网拉取依赖；运行时调用外部 LLM/Embedding API |

> 不要求本地推理服务。后端通过 OpenAI 兼容 API 调用聊天 / Embedding / Reranker 模型（`env.example` 为厂商接口示例，仅作说明，可按需替换）。

---

## 二、后端安装与配置

在仓库根目录（含 `pyproject.toml` 的目录）执行：

### 方式 A：uv（推荐）

```powershell
uv sync --extra api --extra test
```

### 方式 B：pip

```powershell
py -m pip install -e ".[api,test]"
```

### 配置密钥

```powershell
Copy-Item env.example .env   # 复制模板为 .env
# 然后编辑 .env，填写 YUSU_LLM_* / YUSU_EMBED_* / YUSU_RERANK_*
```

> `.env` 已被 `.gitignore` 保护，不会提交；请勿把密钥写入任何代码/文档。

### 环境变量说明（详见 `.env` / `env.example`）

| 变量 | 必填 | 说明 |
|---|---|---|
| `YUSU_DATA_DIR` | 否 | 数据/向量/SQLite 落盘目录，默认 `./yusu_data` |
| `YUSU_LLM_BASE_URL/API_KEY/MODEL` | 是 | 聊天模型（OpenAI 兼容） |
| `YUSU_EMBED_*` | 是 | Embedding；未配置回退 LLM 配置，`YUSU_EMBED_DIM` 可选 |
| `YUSU_RERANK_*` | 否 | Reranker，留空不使用 |
| `YUSU_API_KEY` | 否 | 可选 API 鉴权令牌 |

## 三、前端安装与构建

```powershell
cd yusu_webui
bun install
bun run build     # 产物生成到 yusu_webui/dist/
cd ..
```

构建完成后，后端会自动托管前端（`_mount_webui` 检测 `yusu_webui/dist`），启动后端后直接访问 `http://<host>:8920` 即可。

> 开发模式（可选，热更新）：在 `yusu_webui` 下 `bun run dev`，连接页填写 `http://127.0.0.1:8920`。

---

## 四、一键部署脚本（Windows PowerShell）

仓库提供 `scripts/start.ps1`，自动完成：前置检查 → 安装后端依赖 → 复制 `.env`（如缺）→ 安装前端依赖 → 构建前端 → 启动后端服务。

```powershell
cd 仓库根目录
.\scripts\start.ps1
```

脚本行为：
- 缺 `bun` / `uv` 会在终端给出安装提示并跳过对应步骤。
- 缺 `.env` 时自动从 `env.example` 复制，并要求你先补好密钥。
- 后端以 `py -m yusu_kb.server` 在 `0.0.0.0:8920` 启动；按 `Ctrl+C` 停止。

> Linux / macOS：脚本 `scripts/start.sh` 亦可参考（如未提供，按 §二/三 逐步执行等价）。

## 五、启动后端（手动）

```powershell
# 方式一：uv
uv run --extra api python -m yusu_kb.server --host 0.0.0.0 --port 8920

# 方式二：模块
py -m yusu_kb.server

# 方式三：入口命令（若已 pip install -e）
yusu-server
```

访问：
- WebUI：`http://localhost:8920/`
- 健康检查：`http://localhost:8920/health`
- 可选 API 文档：FastAPI 默认在 `http://localhost:8920/docs`（据路由器前缀而定）

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 已在运行（端口占用 Error 10048） | 先停掉占用 8920 的进程，或 `--port` 换端口 |
| 页面显示但不加载 / 白屏 | 确认 `yusu_webui/dist` 已构建；浏览器硬刷新（Ctrl+F5） |
| 忘记填 .env 密钥 | 补全 `YUSU_LLM_API_KEY` / `YUSU_EMBED_API_KEY` 后重启 |
| 首次启动较慢 | 首次安装依赖并构建前端需较长时间，属正常 |
